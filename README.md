Deskripsi Singkat Fungsi Aplikasi:
Umanari Cafe merupakan website yang dibuat untuk memperkenalkan cafe, menampilkan informasi mengenai cafe, menu makanan dan minuman, serta menyediakan informasi kontak dan ulasan pelanggan. Website ini memiliki beberapa halaman, yaitu Home, About, Katalog, Hubungi, dan Review. Website dirancang dengan tampilan minimalis menggunakan perpaduan warna sage green, krem, dan putih
